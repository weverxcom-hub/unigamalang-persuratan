## Keputusan / rekomendasi
Urutan skill audit:
1. `/security-review`: login, hak akses antar peran, akses file Drive, rahasia env, webhook.
2. `/code-review` (level `high`): bug logika, terutama race condition penomoran surat (dua surat bisa dapat nomor sama).
3. `superpowers:systematic-debugging`: cari akar masalah sebelum memperbaiki.
4. `superpowers:test-driven-development`: tes untuk bagian kritis (penomoran, upload Drive, hak akses).
5. `superpowers:verification-before-completion`: verifikasi sebelum menyatakan selesai.
6. `karpathy-guidelines`: perbaikan kecil dan terarah.
- Database (Neon Postgres + Prisma) tidak punya skill khusus; diperiksa manual lewat code review: skema, index, transaksi, migrasi, backup/pemulihan.
